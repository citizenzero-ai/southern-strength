# Southern Strength — website prototype

Clickable prototype of the Southern Strength catalog site (Red Clay direction), covering seven pages: Home, Racks & rigs, Product detail, Lethal Strength, MyCardioFlow, Quote & consultation, and Visit & contact.

## Publish with GitHub Pages

1. Upload everything in this folder (`index.html`, the `images` folder, `.nojekyll`, this README) to the root of a repository.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. The site appears at `https://<your-username>.github.io/<repository-name>/` within a minute or two.

Pages are switched inside `index.html`, so links look like `index.html#SiteBrandLethal`. The "Prototype page" menu in the bottom-right corner jumps to any page.

Text in [brackets] is placeholder content still to be supplied.
